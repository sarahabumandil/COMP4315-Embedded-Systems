## Installation Verification

After installing, open your terminal (Command Prompt on Windows, or Terminal on macOS/Linux) and run the following commands to verify everything is set up correctly:

### 1. Python Verification
Run this command to check your Python version:
```bash
python --version
```
*Expected Output:* `Python 3.14.9`

### 2. PyCharm Verification
* Open **PyCharm** from your applications menu.
* Create a simple project and verify it automatically detects the Python 3.14.9 interpreter you installed.

### 3. Arduino IDE Verification
* Open **Arduino IDE**.
* Go to **Tools** > **Board** and ensure your target microcontrollers (e.g., Arduino Uno) are listed in the boards manager.
