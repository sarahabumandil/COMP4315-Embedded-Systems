## Objective & Tasks
Perform the **"Blink LED"** experiment using Proteus simulation software and an Arduino microcontroller.

### 1. Setup Phase
- Ensure **Arduino** library components are successfully added to your **Proteus** software.

### 2. Experiment Execution
- Build the **Blink LED** circuit architecture in Proteus.
- Write the blink control program in the Arduino IDE.
- Compile your sketch in Arduino IDE to generate the executable `.hex` file.
- Load the `.hex` file into the Proteus Arduino component and simulate to ensure the LED blinks successfully.
